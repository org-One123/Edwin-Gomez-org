# ✔️ Definition of Done (DoD) - Criterios de Finalización

Para considerar que una tarea o Historia de Usuario está completamente finalizada (**Done**), debe cumplir con la siguiente lista de verificación:

- [ ] **Código completado:** La funcionalidad cumple con todos los criterios de aceptación descritos.
- [ ] **Revisión de Código (Code Review):** Al menos un miembro o administrador (`CODEOWNERS`) revisó y aprobó el Pull Request.
- [ ] **Pruebas:** Se verificó el correcto funcionamiento en entorno local sin errores en consola.
- [ ] **Sin conflictos:** La rama está sincronizada con `main` y no genera conflictos de fusión.
- [ ] **Documentación:** Se actualizaron los archivos `.md` correspondientes si hubo cambios arquitectónicos o nuevos pasos de configuración.
